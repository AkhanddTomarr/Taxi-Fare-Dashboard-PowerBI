OVERVIEW:

This project analyzes taxi ride data using Power BI to identify booking trends,
revenue patterns, peak hours, trip distribution, and customer behavior.
The dashboard helps businesses understand operational performance and make
data-driven decisions.

Problem Statement:

Taxi operators generate thousands of trips every day.

The challenge is converting raw trip data into meaningful business insights
such as

• Revenue
• Average Fare
• Peak Hours
• Trip Distance
• Payment Method
• Location Analysis

This dashboard solves that problem.
